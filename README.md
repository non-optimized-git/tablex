# TableX 表析

问卷数据分析工具，解析 Excel 导出文件，生成三个并排表格（计数、百分比无高亮、百分比有高亮）。

## 功能特性

- **Excel 解析** - 支持 .xlsx、.xls 文件，拖拽或点击上传
- **基础表头** - 选择列后点击选项快速创建表头
- **复杂表头** - 支持跨列选择，列内 OR、列间 AND
- **模块管理** - 可手动添加、删除、重命名模块
- **滑动选择** - 按住鼠标滑过题目批量选择/取消
- **配置导入导出** - 支持保存和恢复配置
- **暖色调 UI** - 深棕色主题，简洁优雅

## 快速开始

```bash
cd ~/Documents/GitHub/tablex
python3 -m http.server 9000
# 访问 http://localhost:9000/index.html
```

## 使用说明

### 1. 上传 Excel 文件
- 拖拽文件到上传区域，或点击选择文件
- 上传后显示文件名（加粗）、行数、列数

### 2. 表头设置

#### 基础表头
- 选择一个列 → 显示该列所有唯一值
- 点击选项成为表头

#### 复杂表头
- 点击"+ 添加复杂表头"
- 选择列 → 选择选项（可多选，OR 关系）
- 可添加多个条件（AND 关系）
- 同一选项可出现在多个表头中

### 3. 题目选择
- 勾选/取消勾选题目
- 支持滑动批量选择（按住鼠标滑过）
- 使用"全选"/"全不选"快速操作

### 4. 下载 Excel
- 点击"下载 Excel"按钮
- 文件名格式：`上传文件名_MMddHHmm.xlsx`
- 每个模块生成一个 Sheet
- 每个题目输出 3 个并排表格：
  - Table 1: 计数（次数）
  - Table 2: 百分比
  - Table 3: 百分比 + 高亮（绿=最高，红=最低）

## 排序规则

- **题目顺序**：按 Excel 原始列顺序
- **选项顺序**：按 Total 的选择人数倒序排列
- **表头顺序**：按用户添加/拖拽排序的顺序
- **选项完整性**：即使某个表头没有选择某选项，只要 Total 有，也会显示

## 技术栈

- **前端** - 纯 HTML/CSS/JavaScript，无构建步骤
- **Excel 解析** - SheetJS (xlsx.full.min.js)
- **Excel 导出** - ExcelJS (exceljs.min.js)
- **部署** - Vercel
