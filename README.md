# TableX 表析

问卷数据分析工具，解析 Excel 导出文件，生成三个并排表格（计数、百分比、百分比+色阶），一键导出格式化 Excel 报告。

## 功能特性

- **Excel 解析** - 支持 .xlsx、.xls 文件，拖拽或点击上传
- **基础表头** - 选择列后点击选项快速创建表头（多选列按英文逗号分割为独立选项）
- **复杂表头** - 跨列条件组合，支持任意 `(A 且 B) 或 (C 且 D)` 表达式；三级且/或关系（条件值内、条件间、条件组间）；条件组灰阶配色；保存前实时显示命中人数
- **多选匹配** - 多选单元格按英文逗号分割后逐项命中条件值（与选项数据同口径）
- **模块管理** - 可手动添加、删除、重命名模块，每个模块导出为一个 Sheet
- **滑动选择** - 按住鼠标滑过题目批量选择/取消
- **配置导入导出** - localStorage 自动保存，支持导出/导入 JSON 配置
- **黑白灰极简 UI** - 界面纯黑白灰，无暖色
- **Excel 导出** - 3 个并排表格（计数 / 百分比 / 百分比+色阶），Table 3 红→黄→绿三色渐变
- **独立运行** - 提供单文件版 `tablex-standalone.html`，免服务器双击即用

## 快速开始（本地服务器）

```bash
cd ~/Documents/GitHub/tablex
python3 -m http.server 9000
# 访问 http://localhost:9000/index.html
```

## 独立运行（免服务器）

直接用浏览器打开 `tablex-standalone.html` 即可（双击文件或拖入浏览器窗口）：

- 全部 CSS/JS 内联在单个 HTML 文件里，不依赖本地服务器
- SheetJS / ExcelJS 走 CDN，首次打开需联网（之后走浏览器缓存）
- 功能与多文件版完全一致

**维护注意**：`tablex-standalone.html` 是 `index.html` + `assets/css/styles.css` + `assets/js/app.js` 的手动合并副本，改了多文件版必须同步到 standalone。校验：

```bash
node tests/check-standalone.js   # 内联脚本语法 + 关键常量一致性
```

## 使用说明

### 1. 上传 Excel 文件
- 拖拽文件到上传区域，或点击选择文件
- 上传后显示文件名（加粗）、行数、列数

### 2. 表头设置

#### 基础表头
- 选择一个列 → 显示该列所有唯一值（多选列按英文逗号分割）
- 点击选项成为表头（支持拖拽排序）

#### 复杂表头
- 点击"+ 添加复杂表头"
- **条件值内 且/或**：同一条件勾选多个值可选 任一（或，默认）/ 全部（且，多选题须同时含所选选项）
- **条件间关系**：同一条件组内各条件可选 且/或（默认 且）
- **条件组之间关系**：可选 且/或（默认 且）
- **允许重叠**：同一行数据可出现在多个表头中（重复计算）
- 编辑时「保存表头」按钮旁实时显示当前条件命中人数

### 3. 题目选择
- 勾选/取消勾选题目
- 支持滑动批量选择（按住鼠标滑过）
- 使用"全选"/"全不选"快速操作

### 4. 下载 Excel
- 点击"下载 Excel"按钮
- 文件名格式：`上传文件名_MMddHHmm.xlsx`
- 每个模块生成一个 Sheet
- 每个题目输出 3 个并排表格：
  - Table 1: 计数（次数）
  - Table 2: 百分比
  - Table 3: 百分比 + 红→黄→绿三色渐变

## Excel 导出格式

- 布局：`选项 | Total | 分组1 | 分组2 | ...` × 3 个表格
- **标题行**：自动简化后的题干（≤16 字），加粗大字；副标题为完整题干 + 题目类型（单选/多选）
- **表头行**：底色 `#D9D9D9` 中性灰，加粗
- **base 行**：有效用户数，斜体浅灰字 `#A6A6A6`
- **平均分行**（仅量表题）：加权平均分，暖米色底 `#FBE5D6`，加粗，两位小数
- **数据行**：各选项的计数或百分比（选项列不加粗）

### Table 3 色阶规则

红→黄→绿三色渐变（同 Excel 三色色阶）：最低=红 `#F8696B`，中点=黄 `#FFEB84`（数据中位数），最高=绿 `#63BE7B`。

- 把**整个数据区（所有行 × 分组列）当一个整体**归一化，不逐行标记
- **Total 列不上色、不参与极值**
- max = min 时不上色；无表头时无着色单元格

### 标题简化规则（getShortTitle）

导出大标题自动简化：去除 HTML 标签、题型标签（单选/多选/量表…）、开头提问短语（请问你…/你的/您的）、品牌词、结尾问句与语气词（哪些…？/什么…？/了吗？/了/的）、列编号前缀；空结果回退取原文前 20 字，最终截断至 16 字。副标题（cleanHeader）仅去 HTML 标签和列编号前缀，保留完整题干。

## 排序规则

- **题目顺序**：按 Excel 原始列顺序
- **选项顺序**：按 Total 的选择人数倒序排列
- **表头顺序**：按用户添加/拖拽排序的顺序
- **选项完整性**：即使某个表头没有选择某选项，只要 Total 有，也会显示


## 技术栈

- **前端** - 纯 HTML/CSS/JavaScript，无构建步骤
- **Excel 解析** - SheetJS (xlsx.full.min.js)
- **Excel 导出** - ExcelJS (exceljs.min.js)
- **部署** - Vercel（`vercel.json` outputDirectory = `.`）
